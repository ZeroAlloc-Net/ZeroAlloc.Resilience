# ZR0007 — Interface Shape Not Supported

**Severity:** Error

The interface carries a policy attribute, but it has a shape the generator cannot build a valid proxy for. Rather than emit code that fails to compile with a compiler error that points into generated code, the generator reports ZR0007 with the reason and emits no proxy for the interface.

| Shape | Why no proxy can be generated |
|---|---|
| A generic interface, such as `IRepository<T>`, or an interface nested in a generic type | The generated proxy, policies class and DI extension are not generic, so they cannot name `T`. |
| An interface that is `private`, `protected` or `private protected`, or nested in a type that is | The generated classes are top-level, so they cannot access it. `internal` and `public` are fine. |
| The interface, or a base interface, declares a `static abstract` or `static virtual` member | A proxy instance cannot implement a static member, and an interface with one cannot be the type argument the DI registration needs. |
| A policy applies to an async method with a `ref`, `out`, `in` or ref struct parameter, such as `ReadOnlySpan<char>` | An async method cannot have them, so the method cannot be wrapped in a policy. |
| A policy applies to a method that returns by `ref` or `ref readonly` | A policy-wrapped method cannot return a reference to the inner result. |

Before 3.0, each of these either got no proxy or failed with a compiler error such as CS0246, CS0122, CS0535, CS8920, CS1988, CS4012 or CS8152.

The two method cases apply to the interface's own methods and to inherited abstract ones. An inherited method with a default body is forwarded without its policies instead, with warning [ZR0006](ZR0006.md). Without a policy, both kinds of method are forwarded: without `async`, or as `=> ref ...`.

---

## Example

```csharp
// ZR0007: 'IRepository' is not supported by the resilience generator: it is generic, and the
// generated proxy and policies classes are not. No proxy is generated for it.
[Retry(MaxAttempts = 3)]
public interface IRepository<T>
{
    ValueTask<T> GetAsync(int id, CancellationToken ct);
}
```

---

## How to fix

Put the policy on a non-generic interface that closes the type argument, and use that interface in your code:

```csharp
public interface IRepository<T>
{
    ValueTask<T> GetAsync(int id, CancellationToken ct);
}

[Retry(MaxAttempts = 3)]
public interface IOrderRepository : IRepository<Order> { }
```

For the other shapes:

- Make the interface `internal` or `public`.
- Move the static members to a separate interface that the proxied interface does not inherit.
- Give the async method a return value in place of its `out` or `ref` parameters, pass a `ReadOnlyMemory<T>` in place of a span, or remove its policies.
- Remove the policy from a method that returns by reference.
