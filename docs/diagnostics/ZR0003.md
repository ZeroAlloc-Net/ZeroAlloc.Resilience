# ZR0003 — Policy Cannot Build a Failure for This Result Error Type

**Severity:** Error

The method returns `ValueTask<Result<T, E>>` or `Task<Result<T, E>>` with an error type `E` other than `ResilienceError`, and one of its policies has to return a failure when there is no inner Result to hand back. The generator cannot construct an arbitrary `E`, so it reports ZR0003 and generates no proxy for the interface.

The policies that trigger it:

| Policy | Why | Return types |
|---|---|---|
| `[RateLimit]` | A rejected call never reaches the inner service. | async `Result<T, E>` |
| `[CircuitBreaker]` without `Fallback` | While the circuit is open, the inner service is not called. | async `Result<T, E>` |
| `[Retry(NonThrowing = true)]` | `NonThrowing` promises a `ResilienceError` failure, which `E` cannot hold. | `Result<T, E>` and `UnitResult<E>`, sync or async |

A synchronous `Result<T, E>`, and a `UnitResult<E>` sync or async, under `[RateLimit]` or a `[CircuitBreaker]` without `Fallback` do not trigger ZR0003. Those compiled before ZR0003 existed, so they keep throwing `ResilienceException` when the call is rejected.

`[Retry]` and `[Timeout]` do not trigger it: they return the inner call's own Result unchanged. See [Result Return Types](../guides/result-return-types.md#foreign-error-types).

---

## Example

```csharp
public readonly record struct HttpError(int StatusCode);

// ZR0003: a rate-limited call has no Result<ModelList, HttpError> to return
[Retry(MaxAttempts = 3, BackoffMs = 200)]
[RateLimit(MaxPerSecond = 5)]
public interface IJevApi
{
    ValueTask<Result<ModelList, HttpError>> ModelsAsync(CancellationToken ct);
}
```

---

## How to fix

Pick one:

- **Remove the policy** from that method, for example with a method-level override, or move rate limiting to the transport.
- **Add a fallback** for a circuit breaker. The fallback returns the same Result type, so an open circuit has a value to return:

  ```csharp
  [CircuitBreaker(MaxFailures = 5, ResetMs = 1_000, Fallback = nameof(ModelsFallback))]
  public interface IJevApi
  {
      ValueTask<Result<ModelList, HttpError>> ModelsAsync(CancellationToken ct);
      ValueTask<Result<ModelList, HttpError>> ModelsFallback(CancellationToken ct);
  }
  ```

- **Remove `NonThrowing = true`**. Without it, retry returns the inner Result unchanged, and throws `ResilienceException` only when every attempt threw.
- **Return `Result<T, ResilienceError>`**, whose failures the generator can build.
