# ZR0015 — Policy Not Applied to a Stream Method

**Severity:** Warning

A method that returns `IAsyncEnumerable<T>` takes `[Retry]` alone, and is retried only until its first item. See [Streams](../core-concepts/retry.md#streams). ZR0015 is reported at the stream method when a policy it cannot apply comes from somewhere other than its own attributes:

| Where the policy comes from | What happens |
|---|---|
| `[Timeout]`, `[CircuitBreaker]` or `[RateLimit]` on the interface | Left off the stream method. The interface's other methods keep it. |
| An interface-level `[Retry]` with `PerAttemptTimeoutMs` above 0 | The stream method is retried without the per-attempt timeout. The other methods keep it. |
| The same attributes on an inherited method's declaration in a base interface | Left off that stream method in this interface's proxy. The base interface reports its own [ZR0014](ZR0014.md). |

When nothing is left, the stream method is forwarded to the inner service unchanged. The same attributes on the stream method itself are [ZR0014](ZR0014.md), an Error.

---

## Example

```csharp
// ZR0015 warning at StreamAsync: [Timeout] from 'IMessagesApi' is not applied to 'StreamAsync',
// because it returns IAsyncEnumerable<T>: a stream method takes [Retry] alone, without
// PerAttemptTimeoutMs, and is retried only until its first item. Move [Timeout] from
// 'IMessagesApi' onto the methods that need it.
[Retry(MaxAttempts = 3)]
[Timeout(Ms = 30_000)]
public interface IMessagesApi
{
    ValueTask<Message> SendAsync(MessageRequest request, CancellationToken ct);
    IAsyncEnumerable<MessageEvent> StreamAsync(MessageRequest request, CancellationToken ct);
}
```

---

## How to fix

- Move the policy from the interface onto the methods that need it, so the stream method no longer inherits it.
- For an inherited method's attribute, remove it from the base interface's declaration.
