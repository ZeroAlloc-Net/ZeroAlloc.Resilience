# ZR0012 — [RetryAttempt] Parameter Type Not Supported

**Severity:** Error

`[RetryAttempt]` works only on an `int` or `int?` parameter passed by value. ZR0012 is reported at the parameter for any other type, such as `long`, `string` or `int[]`, and for a `ref`, `out`, `in` or `ref readonly` parameter, even of type `int`. The proxy cannot pass the retry number to it.

---

## Example

```csharp
[Retry(MaxAttempts = 3)]
public interface IJevApi
{
    // ZR0012: [RetryAttempt] on parameter 'retryCount' of 'EvaluateAsync' requires an 'int' or
    // 'int?' parameter passed by value, but it is 'string'
    ValueTask<string> EvaluateAsync([RetryAttempt] string? retryCount, CancellationToken ct);
}
```

---

## How to fix

Change the parameter to `int?`, which is `null` on the first attempt and then `1`, `2`, and so on, or to `int`, which is `0`, `1`, `2`, and so on. If the inner call needs another representation, convert the number there.
