# ZR0011 — [RetryAttempt] Has No Effect Without [Retry]

**Severity:** Warning

A parameter has `[RetryAttempt]`, but no `[Retry]` applies to its method, so there is no retry number to pass. The proxy passes the caller's argument to the inner call unchanged, as if the attribute were not there.

It is reported at the parameter when:

- the method is declared in an interface the generator builds a proxy for, one with `[Retry]`, `[Timeout]`, `[RateLimit]` or `[CircuitBreaker]` on the interface or on a method it declares, and neither the method nor the interface has `[Retry]`. That proxy calls the method once, so it never passes a retry number; or
- the method is not a method of an interface, for example a method of the class that implements it. Only the generated proxy of an interface passes the retry number.

A `[RetryAttempt]` on a method of an interface with no resilience attributes is never reported. Such an interface is typically a base meant to be inherited: an interface with `[Retry]` that inherits it, in the same project or another one, retries the method in its own proxy, and `[RetryAttempt]` takes effect there.

---

## Example

```csharp
[Timeout(Ms = 5_000)]
public interface IJevApi
{
    // ZR0011: [RetryAttempt] on parameter 'retryCount' of 'EvaluateAsync' has no effect,
    // because neither 'EvaluateAsync' nor 'IJevApi' has [Retry].
    ValueTask<string> EvaluateAsync([RetryAttempt] int? retryCount, CancellationToken ct);
}
```

---

## How to fix

Add `[Retry]` to the method or to the interface:

```csharp
[Retry(MaxAttempts = 3)]
[Timeout(Ms = 5_000)]
public interface IJevApi
{
    ValueTask<string> EvaluateAsync([RetryAttempt] int? retryCount, CancellationToken ct);
}
```

If the method is not meant to be retried, remove `[RetryAttempt]`. If it is meant to be retried only through an interface that inherits it, move it to an interface without resilience attributes of its own.
