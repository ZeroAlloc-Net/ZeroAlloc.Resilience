# ZR0011 — [RetryAttempt] Has No Effect Without [Retry]

**Severity:** Warning

A parameter has `[RetryAttempt]`, but no `[Retry]` applies to its method, so there is no retry number to pass. The proxy passes the caller's argument to the inner call unchanged, as if the attribute were not there.

It is reported at the parameter when:

- neither the method nor the interface that declares it has `[Retry]`, and no interface in the same project that inherits that interface has one; or
- the method is not a method of an interface, for example a method of the class that implements it. Only the generated proxy of an interface passes the retry number.

---

## Example

```csharp
[Timeout(Ms = 5_000)]
public interface IJevApi
{
    // ZR0011: [RetryAttempt] on parameter 'retryCount' of 'EvaluateAsync' has no effect,
    // because neither 'EvaluateAsync' nor 'IJevApi' has [Retry].
    ValueTask<string> EvaluateAsync([RetryAttempt] int? retryCount, CancellationToken ct);
}
```

---

## How to fix

Add `[Retry]` to the method or to the interface:

```csharp
[Retry(MaxAttempts = 3)]
[Timeout(Ms = 5_000)]
public interface IJevApi
{
    ValueTask<string> EvaluateAsync([RetryAttempt] int? retryCount, CancellationToken ct);
}
```

If the method is not meant to be retried, remove `[RetryAttempt]`.

---

## When to suppress

An interface-level `[Retry]` also applies to the methods an interface inherits, in that interface's proxy. When the `[Retry]` interface is in another project than the base interface that declares the method, the base interface's project cannot see it and still reports ZR0011. The attribute does take effect in the other project's proxy, so suppress the warning at the parameter:

```csharp
public interface IJevApiBase
{
#pragma warning disable ZR0011 // retried by IJevApi in another project
    ValueTask<string> EvaluateAsync([RetryAttempt] int? retryCount, CancellationToken ct);
#pragma warning restore ZR0011
}
```
